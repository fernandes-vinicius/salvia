# Ícones

Lucide, sempre importados de `~/shared/components/icons` (nunca direto de `lucide-react`). Precisa de um ícone novo? Adicione ao `export` desse arquivo primeiro.

```tsx
import { Salad } from "~/shared/components/icons";

<Salad className="size-4 text-primary" />
```
