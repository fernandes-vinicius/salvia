## Macros

A cor **base** é pra barras e bolinhas; a **ink** é a mesma cor em tom de texto, com contraste garantido.

## Como usar

```tsx
<div className="rounded-3xl bg-card p-4">          {/* superfície */}
	<p className="text-muted-foreground">…</p>        {/* texto secundário */}
	<span className="text-macro-carb-ink">153 g</span> {/* valor de macro */}
	<div className="h-2 rounded-full bg-macro-carb" /> {/* barra de macro */}
</div>
```
